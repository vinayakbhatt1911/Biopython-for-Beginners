# Biopython-for-Beginners

# 🧬 BioPython for Beginners

A beginner-friendly collection of BioPython programs for learning biological sequence analysis.

This repository contains basic BioPython examples covering DNA sequence manipulation, FASTA file handling, sequence analysis, and pairwise sequence alignment.

---

# 📚 Topics Covered

## 1. FASTA File Handling

- Reading FASTA files
- Writing FASTA files
- Working with SeqRecord
- Reading multiple sequences using SeqIO

---

## 2. DNA Sequence Analysis

- DNA Length
- Nucleotide Counting
- GC Content Calculation
- Reverse Complement
- DNA Transcription
- Protein Translation

---

## 3. Pairwise Sequence Alignment

- PairwiseAligner
- Match Score
- Mismatch Penalty
- Gap Penalty
- Alignment Score
- Best Alignment

---

## 4. NCBI Dataset Analysis

- Reading downloaded NCBI FASTA files
- Extracting sequence information
- Comparing HBB Gene Sequences
